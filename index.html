Server Rules

RULE 01

🚫 Hacked Clients

Using hacked clients will result in a permanent IP ban. You may appeal your ban through our Discord server.

RULE 02

⚠️ Discrimination

Do not discriminate against the server, staff or other players. Violations will result in a 3-day ban. Repeated violations will result in a permanent ban. Repeating this on an alternate account will result in a permanent IP ban.

RULE 03

👁️ Freecam

Using Freecam will result in a permanent ban. You may still play on an alternate account.

RULE 04

📦 Advantageous Resource Packs

Resource packs that give you an unfair advantage in the game are not allowed. Using them will result in a one-month ban.

RULE 05

💬 Spam & Toxic Behavior

Spamming, repeatedly asking for free kits, asking for OP, or using racist language is not allowed.

Your first offense will result in a warning and a reminder to read the rules.

Repeated offenses can result in a 1-hour mute, 3-day ban, 1-week ban, and eventually a permanent IP ban.

RULE 06

🌐 External Advantages

Websites or external tools that give you an unfair advantage are forbidden.

Examples include seed maps or tools that allow you to recreate the world in order to locate bases.

Violations will result in a permanent ban. Repeating this on an alternate account will result in a permanent IP ban.

RULE 07

🕳️ Rule Loopholes

Do not attempt to bypass the rules or exploit loopholes in them.

Violations will result in a ban. Repeating this on an alternate account will result in a permanent IP ban.

RULE 08

💥 Lag Machines

Do not build lag machines or intentionally attempt to crash, overload or lag the server.

Violations will result in a ban. Repeated violations will result in a permanent IP ban.

RULE 09

🏷️ Appropriate Nickname

Always use an appropriate nickname.

Offensive, inappropriate or disruptive nicknames are not allowed.
